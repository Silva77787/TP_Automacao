docker-compose build
docker-compose up

Run and build on detached mode
docker-compose up --build -d 

Make the migrations 
docker-compose exec web python manage.py makemigrations
docker-compose exec web python manage.py migrate

Run the fuction to fill the DB only if no db exists yet
docker-compose exec web python manage.py populate_db

Command to delete the current db, if you run this you need to run the one above again
Only use the command below if really nedeed as the populate_db fucntion takes about 1-3 minutes to run depending on pc
docker-compose down -v

To acess the db directly and try out some queries 
docker-compose exec db psql -U admin -d moviedb
